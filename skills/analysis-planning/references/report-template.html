PBMC 单细胞转录组聚类与细胞类型注释分析

2026.05.28

摘要

本研究对 3 例健康供者外周血单个核细胞（PBMC）开展单细胞 RNA 测序分析。经严格质控保留 8,392 个高质量细胞，基于高变基因主成分与 Leiden 算法鉴定出 12 个细胞亚群，并通过独立的标记基因表达验证完成细胞类型注释。分析刻画了 T/B/髓系/NK 四大谱系的主要亚群及其特征性标记基因，CD4 与 CD8 T 细胞的 naïve/记忆/效应连续分化谱尤为清晰，为后续细胞间通讯与转录因子调控网络研究奠定了可靠的细胞图谱基础。

    分析思路与方法选择

    整体流程遵循 scanpy-prep → scanpy-cluster → scanpy-annotate 的标准范式：先以 scanpy-prep 完成质控、归一化与高变基因选择，再在 scanpy-cluster 中降维聚类并识别标记基因，最后由 scanpy-annotate 的 cluster-identify 流水线完成证据驱动的细胞类型鉴定。每一步关键参数的选取均有明确依据，而非沿用默认值。

    数据预处理与质控

    质控采用三重过滤策略：n_genes_by_counts 介于 200–6,000 之间以剔除低质量细胞与潜在双胞；线粒体基因比例 阈值设为 15%，兼顾去污染与保留高代谢活性细胞；基因表达细胞数 下限为 3。归一化采用 sc.pp.normalize_total + log1p，原始计数存入 adata.raw 供后续可视化与差异分析使用。

    参数依据线粒体比例取 15% 而非常见的 10%，是因为本研究关注包含高代谢活性细胞的亚群（如活化 T 细胞、树突状细胞），过严的阈值会系统性丢失这些真实存在的群体。该取舍经小提琴图人工复核后确认。

    降维、邻接图与聚类

    选取 4,000 个高变基因后执行 PCA，依据肘部图保留前 50 个主成分；以 neighbors(n_neighbors=15, n_pcs=40) 构建 KNN 邻接图，UMAP 用于二维可视化。Leiden 聚类的分辨率经 0.3 / 0.5 / 0.8 / 1.0 四档比较后定为 0.5。

    细胞类型注释策略

    采用两级策略：首先以经典 marker 进行快速人工映射锁定主谱系，再对每个簇调用 cluster_identify.py 的 deg → validate 流程，以独立于差异分析的标记基因表达（点图、小提琴图、UMAP 特征图）交叉验证推断结果。差异检验方法在 Wilcoxon 与 t-test 之间的取舍如下。

    表 2差异表达检验方法对比
    方法假设鲁棒性本项目取舍
    Wilcoxon 秩和非参数对非正态表达稳健采用

    MAST（Hurdle）零膨胀混合最严谨、计算量大关键簇复核

    核心结论

    基于上述流程，本研究在 PBMC 中稳定刻画出四大谱系共 12 个细胞亚群，各亚群均有清晰的标记基因支撑且通过独立表达验证。其中 T 细胞谱系占比最高（约 64%），并呈现出 naïve → 记忆 → 效应的连续分化轨迹。

    三个值得关注的发现：其一，CD4 与 CD8 T 细胞的 naïve/记忆/效应亚群在 UMAP 上呈连续过渡而非离散块状，提示后续可考虑伪时序分析；其二，C5（NK）与 C4（CD8 效应）共享 NKG7/GNLY 但在 KLRD1 与 CD8A 上分离，注释置信度中等、建议人工复核；其三，未检测到明显的双胞污染簇或批次效应驱动的伪簇，质控与整合策略有效。
